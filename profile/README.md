## 🪶 What we stand for

- **Open source, always.** Every line we write ships public under permissive licenses.
- **Privacy is the default,** not a premium tier. No tracking, no ads, no data resale.
- **Self-hostable by design.** If you don't trust our servers, run it on yours.
- **Community over product.** We code together, play together, and ship at our own pace.

## 🛰️ We host what we preach

## 🤝 Contributing

Fork it, break it, fix it, send it back. Pull requests are open to everyone —
no invitation and no membership required.

1. Fork the repository and branch off `dev`
2. Keep commits focused and readable
3. Open a PR — CI will tell you what it thinks
4. Found something broken instead? [Open an issue](https://github.com/orgs/whiteravens20/repositories)
